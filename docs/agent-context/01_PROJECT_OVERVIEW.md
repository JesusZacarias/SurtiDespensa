# Descripción general

## Producto

**SurtiDespensa** es una aplicación móvil que ayuda a decidir qué cocinar durante
la semana y convierte el plan de comidas en una lista de compras completa.

El problema principal es que una persona suele recordar sus recetas, pero puede
olvidar ingredientes o cantidades cuando hace la compra. También le cuesta
decidir qué preparar cada día y ajustar las cantidades al número de comensales.

## Propuesta de valor

El usuario crea un catálogo personal de recetas, organiza una o varias comidas
por día, define para cuántas personas cocinará y deja que la aplicación calcule
y consolide los ingredientes necesarios. Cada cantidad debe conservar su
procedencia para poder responder, por ejemplo: “estos cinco jitomates son tres
para mole y dos para picadillo”.

## Visión

Crear una herramienta cotidiana, sencilla y confiable para planear, comprar y
recordar lo que realmente se preparó. El historial permitirá posteriormente
proponer comidas que no se han preparado recientemente.

## Principios del producto

1. **Local primero:** se puede empezar sin crear una cuenta.
2. **Offline first:** las funciones esenciales operan sin conexión.
3. **Trazabilidad:** las cantidades de compra explican su origen.
4. **Flexibilidad:** una receta puede repetirse y cambiar de porciones cada día.
5. **Aprendizaje práctico:** el proyecto enseña arquitectura, pruebas,
   persistencia, autenticación, sincronización y publicación.
6. **Evolución segura:** primero se termina un ciclo pequeño y funcional; luego
   se agregan colaboración y recomendaciones.

## Personas interesadas

- **Cliente y Product Owner:** el propio creador del proyecto.
- **Usuario inicial:** una persona que planea sus compras y comidas semanales.
- **Equipo de desarrollo:** colaboradores locales o remotos.
- **Usuarios futuros:** familias o grupos que compartirán recetas y planes.

## Plataforma

- Primera publicación: Android / Google Play.
- Segunda etapa: iOS cuando exista acceso a macOS y al ecosistema de Apple.
